# A Polynomial Taking Only Non-Negative Integer Values

Let $p(x)$ be a polynomial with real coefficients such that $p(n)$ is a non-negative integer for every non-negative integer $n$. Suppose also that $p(0) = p(1) = p(2) = 0$.

Must $p(n) \geq 0$ for all $n \geq 0$? And here is the real question:

**What is the minimum possible value of $p(3)$ given that $p$ is not identically zero, $p(0) = p(1) = p(2) = 0$, and $p(n)$ is a non-negative integer for all non-negative integers $n$?**

*Bonus:* Exhibit an explicit polynomial achieving this minimum.
