# The Nowhere-Monotone Continuous Function

A function $f: \mathbb{R} \to \mathbb{R}$ is called **nowhere monotone** if it is not monotone on any open interval $(a, b)$.

We know that a monotone function can have at most countably many discontinuities. 

**Question:** Does there exist a continuous function $f: [0,1] \to \mathbb{R}$ that is nowhere monotone?

If yes, sketch why. If no, prove it.
