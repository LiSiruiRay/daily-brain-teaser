# The Measurable Set That Fills Every Interval

Let $E \subseteq [0,1]$ be a Lebesgue measurable set such that for every open interval $(a,b) \subseteq [0,1]$,

$$0 < m(E \cap (a,b)) < b - a.$$

Must $E$ exist? If so, construct one. And here is the conceptual punch: show that no such $E$ can be **open or closed**.
