# The Monotone Function That Isn't

Let $f: [0,1] \to \mathbb{R}$ be a function that is **differentiable everywhere** on $[0,1]$, with $f'(x) \geq 0$ for all $x \in [0,1]$.

**Must $f$ be monotone (non-decreasing)?**

Now suppose instead we only know that $f'(x) > 0$ for all $x \in [0,1]$.

**Must $f$ be strictly increasing?**

For each case, either prove it or give a counterexample.
