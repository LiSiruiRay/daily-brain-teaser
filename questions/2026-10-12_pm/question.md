# The Function That Is Its Own Average

Let $f: [0,1] \to \mathbb{R}$ be a continuous function satisfying

$$f(x) = \frac{1}{x} \int_0^x f(t)\, dt \quad \text{for all } x \in (0,1].$$

What can you conclude about $f$?
