# The Continuous Function That Must Be Zero

Let $f: [0,1] \to \mathbb{R}$ be a continuous function satisfying

$$\int_0^1 f(x)\, x^n\, dx = 0 \quad \text{for all } n = 0, 1, 2, \ldots$$

Must $f \equiv 0$?

Now suppose instead we only know

$$\int_0^1 f(x)\, x^n\, dx = 0 \quad \text{for all } n = 1, 2, 3, \ldots$$

(i.e., we are missing the $n=0$ case). Must $f \equiv 0$?

For the second condition, either prove $f \equiv 0$ or find an explicit nonzero counterexample.
