# The Conformal Map That Unfolds a Wedge

Let $W_\alpha$ denote the wedge-shaped region
$$W_\alpha = \{ z \in \mathbb{C} : 0 < \arg(z) < \alpha \}, \quad 0 < \alpha \leq 2\pi.$$

**(a)** Find a conformal map from $W_\alpha$ to the upper half-plane $\mathbb{H} = \{ w : \operatorname{Im}(w) > 0 \}$.

**(b)** Now use this to find a conformal map from the **quarter-plane** $\{x > 0,\, y > 0\}$ to the **unit disk** $\mathbb{D}$.

Write down the maps explicitly.
