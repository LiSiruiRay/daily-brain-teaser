# The Argument Principle: Counting Zeros of a Polynomial

Let $f(z) = z^5 + 3z + 1$. Use the **argument principle** (or Rouché's theorem) to determine exactly how many zeros $f$ has inside the unit disk $|z| < 1$.

*Hint: Compare $f$ to a simpler function on $|z| = 1$.*
