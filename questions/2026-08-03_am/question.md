# The Function That Equalizes Its Own Averages

Let $f : [0,1] \to \mathbb{R}$ be a continuous function satisfying

$$\int_0^1 f(x)\, dx = \int_0^1 x\, f(x)\, dx.$$

Prove that there exists a point $c \in (0,1)$ such that

$$\int_0^c f(x)\, dx = 0.$$
