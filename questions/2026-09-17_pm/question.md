# The Entire Function That Grows Too Slowly

Let $f: \mathbb{C} \to \mathbb{C}$ be an entire function satisfying

$$|f(z)| \leq C |z|^{1/2}$$

for some constant $C > 0$ and all $z \in \mathbb{C}$.

What can you conclude about $f$?
