# The Conformal Map That Straightens a Half-Strip

Let $S$ be the open half-strip
$$S = \{ z \in \mathbb{C} : 0 < \operatorname{Re}(z) < \pi,\; \operatorname{Im}(z) > 0 \}.$$

Find an explicit conformal map $f : S \to \mathbb{H}$, where $\mathbb{H} = \{ w : \operatorname{Im}(w) > 0 \}$ is the upper half-plane.

**Hint:** Think about what familiar function maps vertical strips or half-strips to half-planes, and whether composition with a Möbius transformation finishes the job.
