# A Square Vanishing Function Must Be Identically Zero

Suppose $f : \mathbb{R}^2 \to \mathbb{R}$ is a continuous function such that for every axis-aligned square in the plane, the sum of the values of $f$ at the four vertices equals zero.

Must $f$ be identically zero?
