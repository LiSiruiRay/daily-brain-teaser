# The Coloring That Cannot Avoid Arithmetic

Color each positive integer either red or blue. Prove that no matter how the coloring is done, there always exist positive integers $x$ and $y$ (not necessarily distinct) of the same color such that $x + y = z$ for some $z$ of the same color — that is, there exist same-colored $x, y, z$ with $x + y = z$.

More precisely: prove that for any 2-coloring of $\{1, 2, 3, \ldots\}$, there exist positive integers $x, y, z$ all of the same color with $x + y = z$.
