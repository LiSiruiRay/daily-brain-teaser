# The Stone–Weierstrass Gap: A Subalgebra That Misses One Function

Let $A$ be the set of all continuous functions $f : [0,1] \to \mathbb{R}$ such that

$$\int_0^1 f(x)\, dx = 0.$$

Is $A$ dense in $C([0,1])$ (equipped with the uniform norm $\|\cdot\|_\infty$)?

If not, characterize exactly which functions can be uniformly approximated by elements of $A$.
