# The Factorial That Unmasks $e$

Evaluate
$$\lim_{n\to\infty} \; n\,\sin\!\big(2\pi e\, n!\big).$$

For contrast, consider $\sin(2\pi e\,n)$. Since $e$ is irrational, this sequence is dense in $[-1,1]$, so $n\sin(2\pi e n)$ has no limit. Why does replacing $n$ by $n!$ change things so much?

*Bonus:* Use the same idea to prove that $e$ is irrational in one line.
