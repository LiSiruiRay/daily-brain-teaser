# The Casorati–Weierstrass Theorem: Dense Image Near an Essential Singularity

Let $f$ be holomorphic on the punctured disk $0 < |z| < 1$, with an **essential singularity** at $z = 0$.

**Prove** that for every $w \in \mathbb{C}$ and every $\varepsilon, r > 0$, the image $f(\{0 < |z| < r\})$ intersects the disk $|w - c| < \varepsilon$ for all $c \in \mathbb{C}$.

In other words: **the image of any punctured neighborhood of an essential singularity is dense in $\mathbb{C}$.**

As a warm-up sanity check: verify this is consistent with the behaviors $f(z) = e^{1/z}$ near $z=0$.
