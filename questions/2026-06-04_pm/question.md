# A Holomorphic Function That Is Its Own Derivative

Let $f : \mathbb{C} \to \mathbb{C}$ be an entire function satisfying

$$f'(z) = f(z) \quad \text{for all } z \in \mathbb{C},$$

and $f(0) = 1$.

**Without assuming any knowledge of ODEs or the exponential function**, prove using only complex-analytic tools (power series) that $f$ must satisfy

$$f(z+w) = f(z)\,f(w) \quad \text{for all } z, w \in \mathbb{C}.$$

Then conclude: what is $f$?
