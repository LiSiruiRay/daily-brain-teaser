# The Cantor Function Is Uniformly Continuous but Carries No Mass Where It Grows

Let $f: [0,1] \to [0,1]$ be the **Cantor–Lebesgue function** (the "devil's staircase"): $f$ is continuous, non-decreasing, $f(0)=0$, $f(1)=1$, and $f$ is constant on each interval removed in the construction of the Cantor set $C$.

**Question:** Compute $\displaystyle\int_0^1 f(x)\, dx$.

*(Hint: No explicit formula for $f$ is needed.)*
